# 音频分析本地资料

这里保存本机的参考音频、完整片段和可选分离音频。它们用于复现实验，不是训练集，也不代表听觉真值。根目录的 `.gitignore` 默认排除音频扩展名和整个 `data/`，因此个人音频不会被意外提交。

当前工作区已从旧 `F:\LED\sam-audio\clips` 复制 Breeze 样本到 `breeze/`：

- `Breeze-first30s.wav`：Gemini/SAM 的 0–30 秒输入。
- `Breeze-anchor-10.5-12.0.wav`：参考片段。
- `Breeze-first30s.mp3`：原始目录中的兼容试听副本。

如果在另一台机器上使用工具，请把你有权使用的音频放入同一目录，或通过命令行参数传入绝对路径；不要把私人路径或音频凭据写进配置模板。
