# #51 模长与预测身份联合教师（隔离重跑）

本轮落实新的明确修正：教师求 P 时读取预测方向，而不是只在选完包络对应后计算 ID。
[原评论](https://github.com/guajun/anonymous-audio-tracks/issues/51#issuecomment-5981435673)
中的适当时序一致性要求较宽泛；不能把上一轮纯包络教师实验解释为联合教师失败。
旧实现和全部旧结果保留。本轮代码、runs/joint-teacher、证据和报告分开，不合并 PR。

## 完整目标和约束

令 V[t,a] 为原候选，A=norm(V)，E=V/max(norm(V),1e-8)。只有精确零预测方向未定义，
没有 .001 训练硬准入。所有数值在固定 r=.2591032088 的线性 RMS 尺度。
P[t,i,a] 是完整硬排列，一条真实源只能选择一个原候选，一个候选只能分给一条源/零轨。
余下行对应零轨。G[t]=P[t]^T P[t+1] 同样一对一；GT=0 不定义身份。

F(P)=L_amp(P)+.2 L_ID(P;c)，两项都覆盖完整训练片段，不用分块 IoU 代替全段 IoU。
L_amp 完全复用旧训练函数：真实源 Huber(delta=.1)/.1 + .1 全段 area-IoU
+ .1 GT 精确零节点 mean A + .1 未分配候选 mean A。全零源不计 IoU。
L_ID 完全复用直接身份训练函数及其 offset1/2/5/15/30/45、radius45 对集合：
每正对的同源 cosine c+ 与两个异源竞争 c_f/c_r 的
.5[relu(.2+c_f-c+)+relu(.2+c_r-c+)]+.05(1-c+)。
四节点 GT 活动权重 y/(y+.01) 与固定 c 的乘积开方加权；分母只有 GT 活动权重。
负节点来自真实其他源，两个方向是不同竞争，不是重复正对。

为避免教师选择较小置信来逃避损失，c 在求解之前计算并冻结，与 P 无关。
两臂共同使用此 c（这是与上一轮历史 ID.2 实验的共同改动）：
GT 两源全段平均 |y0-y1|/(平均 |y0-y1|+.01)，乘每帧候选单位方向最大差
clip(max(1-E_a dot E_b),0,1)。没有源内归一化，也没有候选模长硬阈值。
单源无异源对；相同 GT 包络或完全复制方向使身份证据为零。
它只是可靠度，不是标签正确性后验；很小空轨的随机方向仍可扩大 spread，因此不能
靠该 c 宣称预测身份已可信。近零 GT 的权重由 GT 活动可靠度连续降低。

额外限制 L_amp(P) <= L_amp(P_env_initial)+.02。初始对应来自旧包络教师但 switch=0，
以限制早期错误 E 牺牲真实源拟合。此界限是显式启发式，不能保证真实身份正确。
不增加候选索引切换成本。时间关系由同源/异源真实有声节点对给出，包含跨静音端点。

首版 fit-v1 的全段界限仍允许小例在某个真实有声节点选择近零候选。该负面诊断和两臂
完整课程保留，不作为最终方案。修正版 fit-v2 额外要求每个 GT 精确非零节点的
|A_selected-y| <= |A_envelope_initial-y|+.02，逐源逐节点约束，而非只约束平均成本。
此保护不保证包络初始化本身正确；在 GT 包络和身份方向冲突时，拟合界限有优先权。
GT0 节点不强迫身份稳定，但仍受模长/空轨损失。完整教师目标与训练损失仍相同，
新约束只是限制可行集合。所有正式两臂重跑采用 fit-v2，首版结果独立保存。

## 求解范围、误差及数据流

实际训练每16帧共享真实源对应：对每块的8P1或8P2全部候选状态做一次顺序坐标搜索。
每次比较的是精确全段 F（完整 IoU 和所有跨块 ID 对），并遵守同一个全段模长上界。
只接受严格下降，保存 before/after/history。完整目标评价精确，但分块限制和单遍坐标
搜索都属于近似；不能声称全局最优或收敛。尚未搜索的多块协同更换可能更好。
块内固定 P 对逐帧候选随机打乱不等变，训练明确保留此分辨率限制。
可枚举小例使用 block=1 穷举全部可行组合，比较坐标搜索的最优性差距与打乱等变性；
独立 torch 训练损失对照 numpy 目标评价，真实评估也保存逐样本绝对误差。
有并列最优时只要求目标及最优解集合在打乱下等变，不伪造唯一标签；训练 block16
依然不能应付块内任意逐帧打乱，不能把预测推理的打乱等变性混作教师等变性。

冻结 SSAST 完整197token缓存 -> WindowVHead(4) -> 原 V/A -> detach V/y
-> 固定可靠度和联合求 P/G -> stop-gradient 对应 -> 原 A 幅度损失 + 原 V 直接 ID。
没有向量平均或方向抵消制造零轨。只有 head 被训练。
主要验证和推理仍是原预测 E/A 连续可靠度、相邻 Hungarian 硬连接；完全不读取 GT/P。
教师对应单独诊断，teacher metric 指定真实行0:S，避免再次 PIT 隐藏教师错误。
