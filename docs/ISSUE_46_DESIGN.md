# Issue #46：连续包络轨迹、课程学习与损失消融草案

状态：讨论稿。尚未实现新训练器、连续标签协议或 Demucs 适配器。

## 当前目标与建议设计约束

- 连续声学包络轨迹是核心监督；描述子 E 只服务局部可匹配性，不要求全局音色不变。
- 候选输出为 V=A·E：方向为单位描述子，模长为活动强度；A 不再解释为活动概率。
- 先做有分轨监督基线，再比较混音训练。混音继续训练与全程不用分轨标签须分别报告。
- 核心损失位于关联之后。片段内只做一次轨迹与参考来源的排列匹配，不逐帧重配。
- 训练关联必须对 E 提供梯度；硬索引关联本身不能把包络错误反传给匹配描述子。
- TimeCycle 首轮关闭；主损失有效后再做开关消融，不强制不同音色的 E 分离。

## 数据管线证据与运行边界

现有 AmpSpec 和 DawDreamer SamplerProcessor 支持 attack、decay、sustain、release。
同次渲染记录 dry、经过效果和 gain 的 stems 及 mix；报告保留完整配置。
labels.energy 已有逐采样点 RMS 与指定采样点的均方提取函数。
当前 labels.pipeline 在输出时把连续电平转换为 0/1，因此缺口主要在标签持久化及消费语义。

2026-10-03 检查 F:/LED 下 11 个可执行的 Python 虚拟环境，均未发现 DawDreamer。
此前程序化 pad 波形及 RMS 提取验证通过；这不等于完整 DawDreamer 采样器渲染验证。
不修改其他项目环境，不把新依赖安装进既有共享环境。

连续目标使用进入混音的效果后分轨 RMS，干声 RMS 作诊断。
保存原始 RMS；所有来源采用相同尺度与变换。不做逐窗峰值归一化。
旧 0/1 标签保留用于事件评估。连续强度需要明确的新语义/版本，不能静默替换 probability。
标签网格建议 20 ms，能量窗先比较 20/50 ms；长能量窗本身会平滑起音。
离线中心窗可用双侧测量，须记录它的时间扩散，不解释成物理零延迟。

## 课程学习

下表范围是建议起点，推进条件应在保留合成集上评估，不是已测性能承诺。

| 阶段 | 数据 | 新增变化 | 目的与推进证据 |
|---|---|---|---|
| C0 | 单音色、单来源、音符和可听尾音均不重叠 | 一个固定音色，先固定音高，再变力度、时长、ADSR | 包络可拟合；无额外槽位发声；起落时间正确。不能据此宣称 E 学会区分来源 |
| C1 | 两音色交错出现，无声学重叠 | A-B-A、随机顺序、长短休止；取消固定槽位/节奏关联 | 休止重现后的轨迹曲线仍对应；交错顺序改变不会换轨 |
| C2 | 两来源轻度重叠 | 重叠率从约 10% 到 25%，先尾音交叠，再错峰起音 | 开始验证真正的同时来源分解；不合并、不重复占槽 |
| C3 | 两来源中度/高度重叠 | 约 25% 到 75%，同时起音、弱来源遮盖、相同包络后分岔 | 匹配错误会影响后续形状；区别局部不可辨认与实际接错轨迹 |
| C4 | 3–4 来源及更像音乐的结构 | 和弦、鼓与旋律、效果、变化音高和节奏 | 检查课程迁移、来源数误差和弱来源包络 |

重叠率使用实际分轨包络超过固定可听性门限的掩码计算：共同活动时间 / 至少一来源活动时间。
不能用 MIDI note-on/off 代替，因为 release 与素材尾音可能造成隐性重叠。
C0/C1 验收必须检查实际分轨；仅增加 MIDI 间隔不保证无声学重叠。

各阶段使用同一渲染基础，简单阶段无需另写一个数据引擎；真实音乐结构放在后期。
早期不要求模型推断音色名称。训练/验证/测试按音色资产、参数组合和序列分组隔离。
单固定音色的 C0 是工程与回归诊断；未见音色泛化从后续课程才开始评估。
推进新阶段时建议保留 20%–30% 旧阶段样本，比例作为可配置建议值。
记录阶段标签、实际重叠率、ADSR、增益、种子、资产与标签参数。

## 损失定义

以下 p(t) 与 y(t) 均指关联后的预测和参考包络，非负，使用共同时间轴及有效掩码。

| ID | 损失 | 特点 | 偏移行为与局限 |
|---|---|---|---|
| L1 | mean(abs(p-y)) | 直接监督绝对强度与时间 | 在同一时间点比较；短起音的偏移会产生不重叠误差；长静音稀释均值 |
| H | mean(Huber_delta(p-y)) | 小残差二次，大残差线性 | 改善残差梯度，不能对齐错位时间轴；delta 按标签尺度固定 |
| I | 1 - sum(min(p,y))/sum(max(p,y)) | 曲线下方区域的面积 IoU，长度与尺度更易比较 | 仍在相同 t 比较；完全不重叠时没有有用的横向对齐方向；空目标需单独处理 |
| D | 1 - 2 sum(min(p,y))/(sum(p)+sum(y)) | 同一区域的面积 Dice | 与面积 IoU 单调等价，首轮不用同时扫；避免与 sum(p*y) 的其他 soft-Dice 定义混淆 |
| M | 多尺度 Huber：sum_s w_s H(G_sigma_s*p, G_sigma_s*y) | 同时约束不同时间尺度的轮廓 | 建议尺度 0/20/50/100 ms（Gaussian 标准差）；粗尺度能产生更宽的重叠，但须保留原尺度约束 |
| W | 一维 Wasserstein-1 / CDF 距离 + 总面积误差 | 把时间上的包络量视为需要搬运的质量 | 纯平移给出随距离增长的成本；分布归一化丢失幅度，必须补面积/幅度项；空曲线另处理 |
| S | 有界统一平移的形状损失 + 偏移惩罚 | 显式允许约一标签步长的误差 | 可选 +/-20 ms 起点，每条轨迹统一平移；不能允许每个音符自由对齐，偏移须报告 |
| T | 带时间带宽约束的 Soft-DTW 类损失 | 可微时间对齐，能比较局部时间形变 | 次轮候选；可能掩盖实际时序错误；需要带宽和绝对时间辅助约束 |

面积 IoU 的二维区域定义为 R_y={(t,a):0<=a<=y(t)}，不用阈值把包络变成二值事件。
记 B=sum(p+y)、D1=sum(abs(p-y))，忽略数值 epsilon 时：

    IoU_area = (B-D1)/(B+D1)
    loss_IoU = 2 D1/(B+D1)

因此面积 IoU 是相对尺度的 L1 几何变换，不能单靠“二维”获得时间平移容忍。
面积积分不是物理能量积分；RMS 曲线下的面积只是形状质量。

W 在两条曲线均有正面积时，用归一化质量的 CDF 差计算 W1（单位秒）。
若用于损失组合，除以固定时间尺度，并补预测/目标总面积的误差。
此处的时间运输是轨迹形状比较；与轨迹到槽位的软一对一关联是两个不同操作。

空目标与空槽统一使用显式非负输出惩罚；不要依赖 IoU 的 epsilon 比例处理静音。
对非空轨迹按轨迹汇总形状项，再平均；避免强来源和长静音吞掉弱来源监督。
这与逐窗归一化标签是不同操作，原始强弱比例不变。

## 首轮组合表

所有组合使用相同骨干、输出头、关联器、课程、划分及预算，cycle=0。
所有组合都有相同空槽/静音惩罚 E0；下表不重复列出。
权重需根据诊断样本的典型量级预先标定后固定，不能默认不同单位的 loss 数值可比。

| Run | 主损失 | 本轮回答的问题 | 优先级 |
|---|---|---|---|
| R0 | L1 | 最直接逐点回归的参照 | 必跑 |
| R1 | H | Huber 是否改善学习稳定性 | 必跑 |
| R2 | I | 相对形状重叠能否单独提供有效监督 | 必跑；静音靠 E0 |
| R3 | H + lambda_I I | 强度拟合与面积形状结合 | 推荐主候选 |
| R4 | M | 多尺度是否改善小偏移下的训练 | 推荐主候选；包含原尺度 H |
| R5 | H + lambda_W W（含面积项） | 时间距离监督是否更有用 | 第二批 |
| R6 | M + lambda_I I | 最好的回归与重叠项是否互补 | R3/R4 有效后再跑 |
| R7 | H + lambda_S S | 是否需要显式小偏移容忍 | 标注/前向偏移诊断后再跑 |
| R8 | H + lambda_T T | 局部形变对齐是否有收益 | 暂缓 |

先用人工可控包络做数值/梯度诊断：精确匹配、10/20/50/100 ms 偏移、幅度减半、
尾音过长、多报短音、漏音、无重叠、全静音及同包络后分岔。
随后 R0–R4 在 C0 进行等预算筛选，再把较好的 2–3 个组合推进 C1–C3。
C0 最优不代表多来源最优；C1/C2 保留一个简单回归参照。
最终候选使用至少 3 个种子，并在固定 C0–C3 验证集合上横向比较。
最后单独比较 cycle 开/关，不把 cycle 与 loss 家族同时改变。

评估所有实验都报告未做时间对齐的 MAE、面积 IoU、onset/offset 偏移、
漏音/多报、弱来源误差、来源数、轨迹接错及运行成本。
允许时间对齐的指标作为额外诊断，不能替代原曲时间轴上的误差。
